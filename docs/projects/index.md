# Project Atlas

A curated map of projects, repositories, documentation and technical artifacts by **Hubert Ronald**.

This is not a complete dump of every repository. It is a structured atlas of work that helps explain the broader builder journey: AI-native products, ML/NLP projects, data and cloud architecture, software foundations, open-source utilities, creative archives and practice work.

## How to read this atlas

Each entry focuses on:

- **period or year**;
- **category**;
- **status**;
- **what it demonstrates**;
- **main stack or technical area**;
- **documentation link**;
- **repository or external link**, when available.
