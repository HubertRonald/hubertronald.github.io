## Accessibility checks

- [x] One `h1` per landing.
- [x] Supporting pages have one primary heading.
- [x] Keyboard focus is visible.
- [x] Header links are keyboard reachable.
- [x] CTA links are keyboard reachable.
- [x] Footer links are keyboard reachable.
- [x] Profile photo has alt text.
- [x] Profile photo has width and height.
- [x] Decorative icons are not announced unnecessarily.
- [x] Links do not rely only on color.

## Link safety

- [x] External landing links use `rel="noopener noreferrer"` whex opened in a new tab.
- [x] GitHub link works.
- [x] Kaggle link works.
- [x] Stack Overflow link works.
- [x] Liasoft link works.
- [x] itch.io link works.
- [x] Internal links work.

## Responsive checks

- [x] No horizontal overflow on mobile.
- [x] Hero stacks correctly on mobile.
- [x] Buttons are touch-friendly.
- [x] Cards collapse to one column.
- [x] Footer links wrap correctly.
- [x] Profile photo is not distorted.

## QA script adjustment

The initial quality script was stricter than VitePress output.

Two adjustments were made:

- Decorative local icons under `/icons/` are ignored for image alt and dimension checks.
- External Markdown links generated by VitePress with `rel="noreferrer"` are accepted as safe link output.

The landing hero image remains explicitly validated through `LandingHero.vue` with alt text, width and height.
