# Before the Landing

Before this site became a technical portfolio and documentation hub, `hubertronald.dev` started with a simple under-construction page.

It was intentionally small: a quiet placeholder while the structure, projects, documentation, and public direction of the site were still being shaped.

That first version belongs to the story of the site. It represents the moment before the portfolio had enough body to become a real landing page.

## Why preserve it?

Because the public site did not appear fully formed.

It started as a simple root page, then grew into a documentation hub, and is now becoming a more complete public map of projects, cloud architecture work, AI-native products, open-source libraries, and creative origins.

Preserving the under-construction page keeps that transition visible.

## What changed after this stage?

The site is evolving toward a landing page that introduces Hubert Ronald as a builder working across:

- data platforms;
- cloud-native systems;
- AI-native products;
- developer enablement;
- open-source and technical documentation;
- creative software roots.

The under-construction page was the pause before that public story became ready to unfold.
